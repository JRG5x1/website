Wi-Fi QR code

Move Jibo to a new network.
Show him a code.

Type your network’s name and password to make the code Jibo scans with his camera. It’s Jibo’s own format, so a regular phone Wi-Fi code won’t work. Everything happens in your browser: your network name and password never leave this page.

Leave the password empty for an open network.

Static IP (optional)

Only if your network needs a fixed address for Jibo. Leave these empty to use DHCP, like most networks.

Your code will appear here.

On Jibo

Scan it.

Open Settings, then Wi-Fi, and tap Change. Tap Jibo’s screen when he asks, then hold the code up in front of his face, where his camera is. If there are two codes, he asks for the next one after the first.

Good to know

Works with most home networks.

Jibo joins open and WPA/WPA2 password networks. Networks that need a username or a sign-in page, and hidden networks, aren’t supported by his scanner. If the screen is too dim to scan, turn up its brightness.
