Why choose 5x1?

The first public Jibo server.

Still Jibo, with more possibilities: original Jibo skills, community-made extras, and local control. 100% free, with no self-hosting.

A fork built for the BEcosystem.

5x1 was the first public Jibo server, and it is 100% free and public with no self-hosting. It is a fully fledged public server built around a 5x1-specific server fork—not an unchanged hosted copy. BEefy connects conversations to BEam skills and BEaker updates. The conversation path was rebuilt to be more efficient and quicker than other servers. 5x1 keeps all of Jibo’s original voice commands and adds more. We have no plans to shut it down anytime soon and intend to keep it running for the foreseeable future; that is our intention, not a guarantee of permanent availability.

5x1 is fully and actively maintained. New features are added all the time.

The 5x1 difference

More features than any Jibo server.

All original voice commands, community-made skills and themes, and a local dashboard—together in one public service.

A fork built for the BEcosystem.

BEefy is a 5x1-specific server fork, integrated with BEam, BEnch, BEaker, and BEacon. 5x1 is more than hosting: it is the public server and the connected software built around Jibo.

All the original commands, and more.

5x1 keeps Jibo’s original voice commands and adds community-made skills, custom themes, local music, cooking videos, and Bad Apple.

Its community catalog and local control panel are part of the same connected experience.

A community-made Store.

Unlike other server stores, the 5x1 Store features community-made skills and themes.

BEacon: more control than any dashboard.

BEacon is a clean, polished web UI on your local network for viewing Jibo’s screen, managing music, changing his eye, managing skills, and updating software.

No account system.

5x1 has no user accounts, sign-up, or account-pairing step. GitHub authorization for some Store installs and pairing for optional integrations are separate from 5x1 accounts.

Hosted conversations still send requests to a server. Read the data-handling section for details.

Availability, with the numbers.

On October 26, 2026, the public status dashboard reported 99.86% uptime for the 5x1 Jetstream API and 100% for the 5x1 OTA API in its rolling 24-hour window. These checks cover monitored endpoints, not every feature or robot connection.

A little more detail

Know what you’re choosing.

What makes 5x1 a good fit for my Jibo?

5x1 has more features than any other Jibo server while keeping all of Jibo’s original voice commands and adding more. BEam adds community-made themes and skills, BEacon gives you more control than any other Jibo dashboard, and 5x1 has no account system.

Does privacy first mean everything runs offline?

No. Hosted conversations send requests to a server. Our privacy commitments describe how those requests are handled: 5x1 does not store speech or connection data, collect usage telemetry, or sell your data. This website has no tracking scripts. Read the data-handling section for the full explanation.

What makes the 5x1 Jibo server different?

5x1 was the first public Jibo server, and it is 100% free and public with no self-hosting. Its BEefy server is a 5x1-specific fork built for the BEcosystem instead of an unchanged hosted instance. It combines BEefy with BEam, BEacon, and BEaker, plus a community Store, the original voice commands and more, no account system, and a public service with published uptime.

Does 5x1 have an account system?

No. 5x1 has no user-account system, sign-up, or account-pairing step. GitHub authorization for some Store installs and pairing for optional integrations are separate.

How reliable are 5x1’s monitored services?

On October 26, 2026, the public status dashboard reported 99.86% uptime for the 5x1 Jetstream API and 100% for the 5x1 OTA API over its rolling 24-hour window. These checks cover monitored endpoints, not every feature or robot connection. See the live status dashboard for current readings.

Does 5x1 plan to shut down soon?

No. We have no plans to shut down the public server and intend to keep it running for the foreseeable future. This is our current intention, not a guarantee of permanent availability.
