A few quick answers

Before you begin.

Is 5x1 software I install on my computer?

5x1 hosts the conversation service, update service, and scripts. BEam and BEnch run on Jibo. BEetle is the setup tool that runs on your computer.

Where are the installation instructions?

The Jibo guide contains the detailed instructions. Start with its getting-started page, or the post-mod page if you already have SSH access.

How do robot skills and services get updated?

BEaker provides BEam and BEnch updates. After setup, the robot’s Settings → Update interface is the place to check for OS and service updates. See the post-mod guide for the full sequence.

Where can I find the code?

Each of the six project pages links to its source repository on GitHub.
