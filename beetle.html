BEetle

A guided way to bring Jibo along.

What BEetle does

BEetle is a desktop wizard for preparing Jibo and installing community software. It guides USB recovery, SSH access, rebooting, and the matching post-mod setup for normal and out-of-box robots.

Setup with a little direction

The project targets Windows, Linux, and macOS. Its wizard provides illustrated steps and keeps session state and backups so setup can be revisited. Check the repository for current builds and platform notes.
